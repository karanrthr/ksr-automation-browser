# Contributing

Open an issue describing the observed problem, Windows version, browser version and extension version. Include minimal reproduction steps using non-sensitive sample data.

For code changes, keep pull requests focused and explain the behavior before and after. Build the affected .NET project and, for extension changes, describe the manual checks performed in an isolated test profile. Do not claim tests passed unless they were run.

Do not commit profiles, cookies, session tokens, real conversations, downloaded media, local logs or bundled browser binaries. The ChatGPT and generic adapters are placeholders; proposed implementations should document their supported workflows and limitations.
